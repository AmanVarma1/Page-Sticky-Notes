📝 Page Sticky Notes

Settings, sync and backup.

Appearance

Sync across devices

Needs Chrome sign-in with sync turned on. Chrome limits synced data to about 100 KB in total and 8 KB per note, so very long notes are kept on this device only.

🤖 AI assistant

Use Groq to chat about the page you're reading, your highlights and your notes. Your API key stays in this browser and is not included in note exports or sync.

Create a key at Groq Console.

Backup

Save every note to a JSON file, or restore from one.

Shortcuts

Alt+Shift+N add a note · Alt+Shift+L highlight selected text · Alt+Shift+H hide/show notes. Change them at chrome://extensions/shortcuts.
